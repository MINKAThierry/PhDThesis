# docs — documentation transversale du dépôt

> **Statut : PROPOSITION — documentation du dépôt** · Source : thèse, version de dépôt ([`../00_these/`](../00_these/README_fr.md)) et registre [`../STATUS_fr.md`](../STATUS_fr.md)

[English version](README_en.md) · [Retour à l'accueil](../README_fr.md)

Ce dossier rassemble les documents qui portent sur le dépôt dans son ensemble et non sur un dossier particulier. Ils ne contiennent aucun résultat scientifique nouveau. Les statuts des éléments décrits sont ceux du registre [`STATUS_fr.md`](../STATUS_fr.md).

| Document | Contenu |
|---|---|
| [correspondance_these_depot_fr.md](correspondance_these_depot_fr.md) | Pour chaque chapitre, section, tableau ou script cité dans la thèse, l'emplacement correspondant dans le dépôt, puis la liste des écarts entre le texte de la thèse et l'organisation réelle du dépôt |
| [historique_fr.md](historique_fr.md) | Chronologie des travaux (préprints, articles, formulations précisées, versions de la formalisation Lean, dépôt de la thèse, construction du dépôt) |
| [procedure_publication_fr.md](procedure_publication_fr.md) | Étapes à suivre après la soutenance pour rendre le dépôt public, l'archiver sur Zenodo et reporter le DOI dans la thèse |

## Lecture conseillée

Un lecteur qui part du manuscrit commence par la correspondance. Un lecteur qui veut savoir d'où vient une version donnée d'un résultat consulte l'historique. La procédure de publication s'adresse à l'auteur. Elle est conservée dans le dépôt pour que chaque étape reste vérifiable après coup.
